# 🌐 Personal Portfolio Website

A fully responsive and thoughtfully designed personal portfolio website.  
This project showcases my professional background, skills, and selected projects in a clean and organized layout.

## ✨ Overview

This portfolio serves as an interactive resume and a central hub for all my professional details. It includes:

- **About Me** – A brief summary of who I am and what I do.
- **Experience** – Details of my work experience and roles.
- **Education** – Academic qualifications and institutions attended.
- **Projects** – A curated list of personal and academic projects.

## 📌 Key Highlights

- Mobile-first, responsive design for all screen sizes  
- Clean, modern layout with easy navigation  
- Focused on readability and user experience  
- Structured content that mirrors a professional CV

## 🎯 Project Goals

- Create an online presence to showcase my work and background  
- Demonstrate frontend development and layout skills 
- Provide a professional point of reference for potential employers or collaborators
